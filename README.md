# 🏹 CYBER-ARCHER // กริยาพิฆาต (Cyber-Archer: Verb Striker)

เว็บแอปพลิเคชันเกมการศึกษาภาษาไทยแนว **AR Motion Game** ที่ใช้เทคโนโลยี Computer Vision และ AI ตรวจจับการเคลื่อนไหวของมือจริงผ่านกล้องเว็บแคม (MediaPipe Hands) เพื่อจำลองการถือคันธนูและง้างสายยิงทำลายคำศัพท์เป้าหมาย โดยออกแบบให้ผู้เล่นควบคุมด้วยสองมือจริงแบบ 100% ไม่พึ่งพาเมาส์หรือคีย์บอร์ด

---

## ⚡ ฟีเจอร์เด่น (Key Features)

* **Touchless & Pure AI Hand Tracking:** บังคับควบคุมด้วยสองมือจริงผ่านกล้อง ไม่ใช้เมาส์ ไม่ใช้คีย์บอร์ด และไม่มีปุ่มคลิกยิงบนหน้าจอ
* **Dual-Hand Archery Kinematics:** 
  * **มือซ้าย:** ควบคุมตำแหน่งและมุมการเล็งของคันธนูพลังงาน
  * **มือขวา (กำหมัด ✊):** เริ่มจับและดึงสายธนู ยิ่งยืดมือถอยห่าง สายธนูจะยิ่งตึงและสะสมแรงส่ง
  * **มือขวา (แบมือ ✋):** ปล่อยสายธนูเพื่อส่งลูกศรพลาสม่าพุ่งไปยังเป้าหมายตามทิศทางเวกเตอร์จริง
* **High-Performance Architecture (60 FPS):**
  * รันโมเดล **MediaPipe Hands Lite (`modelComplexity: 0`)**
  * แยกเลเยอร์วิดีโอกล้องสดผ่าน **CSS Hardware Acceleration** โดยตรง ไม่วาดทับลง 2D Canvas ให้กิน Bus เครื่อง
  * ระบบ **AI Throttling Loop** ป้องกันการเกิด Main-thread Queuing ช่วยให้คอมพิวเตอร์และมือถือเล่นได้ลื่นไหล ไม่กระตุก
* **Dynamic Viewport Mapping (Mobile Support):** มีระบบแปลงพิกัดภาพจากกล้องตามอัตราส่วนหน้าจอจริง (Aspect Ratio Fit) เล่นได้ทั้งบนคอมพิวเตอร์และสมาร์ทโฟน
* **Synthesized Audio Engine (Web Audio API):** ระบบเสียงสังเคราะห์ในตัว (เสียงง้างสายธนู, เสียงปล่อยลูกศร Whoosh, เสียงระเบิดเมื่อยิงถูก และเสียงแจ้งเตือนเมื่อยิงผิด) โดยไม่ต้องโหลดไฟล์ `.mp3` ภายนอก
* **Thai Educational Quiz:** คลังข้อสอบคำกริยาและคำนามภาษาไทย 15 ข้อ พร้อมระบบจับเวลาถอยหลังและบันทึกคะแนน

## 🎮 กติกาการเล่น (Gameplay Rules)

1. ยืนหรือนั่งห่างจากกล้องประมาณ **1 – 1.5 เมตร** ให้กล้องมองเห็นมือทั้งสองข้างชัดเจนในสภาพแวดล้อมที่มีแสงสว่างเพียงพอ
2. **มือซ้าย:** ยกขึ้นมาเพื่อถือคันธนูพลังงาน (สามารถเลื่อนขึ้น-ลง-ซ้าย-ขวาเพื่อเล็ง)
3. **มือขวา:** ทำท่า **กำหมัด ✊** เข้าใกล้คันธนูเพื่อจับสาย จากนั้นดึงมือขวาถอยหลังเพื่อชาร์จพลังสายธนู
4. **การปล่อยยิง:** ทำท่า **แบมือ ✋** ทันที เพื่อปล่อยลูกศรพุ่งไปทำลายออร์บคำศัพท์ทางฝั่งซ้าย
5. **เกณฑ์การให้คะแนน:**
   * ยิงถูก **"คำกริยา"** = `+10 คะแนน`
   * ยิงโดน **"คำนาม"** = `-5 คะแนน`
   * หมดเวลา 30 วินาทีในแต่ละข้อ = ข้ามไปข้อถัดไปทันที

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
* **Styling:** Tailwind CSS, Google Fonts (Orbitron & Prompt)
* **Computer Vision & AI:** Google MediaPipe Hands (`@mediapipe/hands`)
* **Audio Engine:** HTML5 Web Audio API (Synthesizer & Filters)
* **Deployment:** GitHub Pages (Single-file Deployment)

---

## 🚀 วิธีการติดตั้งและขึ้นระบบบน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `cyber-archer`)
2. สร้างไฟล์ชื่อ **`index.html`** ไว้ที่ชั้นนอกสุด (Root Directory)
3. นำโค้ดตัวเกมทั้งหมดไปวางในไฟล์ `index.html` แล้วกด **Commit changes**
4. ไปที่ **Settings** -> **Pages**
   * **Source:** เลือก `Deploy from a branch`
   * **Branch:** เลือก `main` หรือ `master` และโฟลเดอร์เป็น `/(root)` แล้วกด **Save**
5. รอระบบ GitHub Actions บิลด์ประมาณ 1 นาที จะได้ลิงก์ `https://<username>.github.io/<repo-name>/` พร้อมเปิดเล่นได้ทันที (ต้องเข้าผ่านโปรโตคอล `https://` เพื่อให้เบราว์เซอร์อนุญาตให้เปิดกล้อง)
